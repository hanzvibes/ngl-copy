# NGL Copy

A responsive anonymous-message app inspired by the anonymous Q&A format. Built with Next.js App Router and designed for Vercel.

## Run locally

```bash
npm install
npm run dev
``

## Enable message delivery

Message submissions require a Supabase project. Create a table using the SQL below, then set `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in Vercel Project Settings → Environment Variables. Keep the service-role key server-only; never prefix it with `NEXT_PUBLIC_`.

```sql
create table public.messages (
  id bigint generated by default as identity primary key,
  username text not null check (char_length(username) between 1 and 24),
  message text not null check (char_length(message) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.messages enable row level security;
-- Do not create public SELECT policies. Inserts are performed by the server route.
```

The server route validates input and writes messages using the service role. Add rate limiting and a moderation/abuse-report flow before promoting this publicly.

## Deploy to Vercel

Import this repository in Vercel and keep the framework preset on Next.js. Add the Supabase environment variables when ready, then deploy. The anonymous message form intentionally reports a setup error until persistence is configured; it does not pretend a message was saved.
